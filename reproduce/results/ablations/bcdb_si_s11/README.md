# BCDB supplementary ablation results

`additional_variants_selected_folds.csv` retains the selected five-fold accuracies for FRPN_v0_s1, FRPN_v1_s0 and FRPN_v0_s0 from the experiment audit. v indicates volume-fraction input and s indicates the anchor-related structural setting. The two source summary tables retain the with-volume and without-volume model metrics used for the supplementary comparisons.

`source_run_id` records the original run-log identifier. These results correspond to the recorded selected runs; available model checkpoints are enumerated separately in `reproduce/docs/checkpoint_manifest.csv`.
